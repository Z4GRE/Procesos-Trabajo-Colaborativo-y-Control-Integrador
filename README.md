# "Modulo de Automatizacion Aduanero" - Mercado Libre

### [Descripcion_del_Sistema_Propuesto]
El ["Modulo_de_Automatizacion_Aduanero"] es una evolucion del sistema de compras internacionales presente en la plataforma de Mercado libre, que permita una optimizacion en sus tiempos de entrega, reduciendo las fricciones aduaneras y facilitando su expansion por Latinoamerica.

### [Control_de_Versiones]
Se ha decidido separar el trabajo en dos ramas principales:
**Rama Principal [main]:** Utilizado para la publicacion de versiones estables con documentacion aceptada.
**Rama Secundaria(desarrollo):** Utilizada para la experimentacion de areas del proyecto especificas o en desarrollo.

### [Indicadores_de_Control]
**Cobertura de Codigo [Code_Coverage]:** Promediar un minimo del [80%] de cobertura de pruebas en el modulo o modulos que se estan trabajando antes de permitir un merge a la rama principal.
**Frecuencia de Integracion:** Cada desarrollador debe realizar al menos [1_Pull_Request_semanal] para evitar que se descuiden codigos auxiliares o separados por largo tiempo y evitar conflictos que hagan perder tiempo al equipo.

**Tiempo de Resolucion de Code Review:** Los Pull Requests abiertos no deben pasar mas de [24_horas] habiles sin ser revisados por otro miembro del equipo.

**Densidad de Defectos:** Menos de [1_error_critico_o_bloqueante] detectado en el entorno de pruebas por cada ciclo de sprint.


### [Estandar_de_Commits_y_Colaboracion]
**Mensajes de Commit:** Se utiliza lengueja profesional y preciso para el registro de cambios. 
**Pull Requests (PR):** Los cambios de la rama se integran mediante la apertura de un Pull Request, permitiendo la revision tecnica antes del merge definitivo.
